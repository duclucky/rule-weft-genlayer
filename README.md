# RuleWeft

Agree on policy exceptions before buying a one-use protocol permission.

RuleWeft is being built for the GenLayer Projects track. Three authors ratify
exact rules, validators interpret their applicability and declared exceptions,
and deterministic grounded labeling resolves which rules remain effective.
Unresolved prohibition cycles never authorize a request.

Status: implemented and checked locally, not deployed. The latest `npm run check`
passed87 Python tests,6 receipt-parser tests and61 frontend tests, plus semantic
lint, TypeScript and the production build. Runtime feasibility was checked through
unsigned Studio Dev simulations; this is not finalized consensus or GEN movement.
No external execution, legal permission, ODRL conformance or adoption is claimed.

Phase7 remains open because the browser-control service rejects access with
`Local browser use is disabled in Work settings`, even after a fresh control
session and the owner's confirmation that browser use is enabled. Actual
browser-local RPC/CORS verification is pending. Deployment and publication have
not started. See [verification](docs/VERIFICATION.md) and [specification](docs/README.md).
